# DailySense
### Making Sense of Everyday Activities

DailySense is a student-focused lifestyle intelligence application that combines screen time, sleep, physical activity and study habits to help college students understand their daily routines.

It uses behavioural analysis to identify habit patterns and provide personalised insights for improving daily lifestyles.

**Track:** 3 – Know Thyself

**Project Type:** Android Application
